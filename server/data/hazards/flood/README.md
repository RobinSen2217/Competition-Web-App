# Flood events dataset

Generated by `python -m forecaster.hazards import flood` (server/ml); do not edit by hand, re-run the import.
Served by the API under `/api/v1/hazards/flood` (docs/API.md, "Hazards").

Flood events with daily satellite rainfall over each event box (GPM IMERG) and the NISAR soil moisture passes over the same box, from 7 days (rain) / 12 days (soil) before the reported flood period to its end.

## Files

| file | what it is |
|---|---|
| `events.json` | every event (id, name, country, period, bbox, cause, coverage, sources), the tables and their columns, the source datasets |
| `events/<event>/daily.csv` | one row per UTC day: rain over the box and the flood-period flag |
| `events/<event>/soil_passes.csv` | one row per NISAR satellite pass over the box |
| `model/forecast.json` | the flood forecast model results (`python -m forecaster.hazards build flood`) |
| `layers.json` | map layers per event (overlay image, bounds, legend, stats, source); `--layers` of the import |
| `events/<event>/layers/<layer>.png` | the overlay image of a layer (EPSG:4326, bounds in layers.json) |

## `daily` (series)

| column | meaning |
|---|---|
| `date` | UTC day (00:00-24:00 UTC), YYYY-MM-DD |
| `rain_box_mm` | Rain averaged over the event box, mm/day (GPM IMERG Late Run V07; cells weighted by their area inside the box) |
| `rain_wettest_cell_mm` | Rain in the wettest 0.1-degree (~10 km) IMERG cell of the box that day, mm/day |
| `cells_with_data` | Number of IMERG cells in the box with a value that day |
| `in_flood_period` | true on the days of the reported flood period (flood_start..flood_end), false on the 7 days of lead-up rain before it |

## `soil_passes` (observations)

| column | meaning |
|---|---|
| `file` | Source GeoTIFF of the pass (not copied; 200 m EASE-Grid 2.0, 4 bands) |
| `date` | UTC date of the pass, YYYY-MM-DD |
| `utc_time` | UTC time of the pass, YYYY-MM-DD HH:MM |
| `local_time` | Local time of the pass, YYYY-MM-DD HH:MM |
| `track` | NISAR track number |
| `direction` | ASCENDING or DESCENDING orbit |
| `frames` | Frames merged for the pass |
| `phase` | before / onset / during / receding / after / unclear, relative to the flood timeline |
| `in_reported_flood_period` | true if the pass falls in the reported flood period |
| `cells_in_box` | Number of 200 m cells in the event box |
| `cells_with_soil_moisture` | Cells with a soil moisture value (open water, towns, snow and heavy rain are empty) |
| `coverage_pct` | % of the box with a value |
| `mean_sm` | Box mean soil moisture, m3/m3 (all values) |
| `median_sm` | Box median soil moisture, m3/m3 |
| `p10_sm` | 10th percentile of soil moisture in the box, m3/m3 |
| `p90_sm` | 90th percentile of soil moisture in the box, m3/m3 |
| `mean_sm_recommended_only` | Box mean of "recommended" retrievals only (dense vegetation left out), m3/m3; the value the flood model uses |
| `cells_recommended` | Cells with a recommended retrieval |
| `mean_uncertainty` | NASA's mean uncertainty estimate, m3/m3 |
| `phase_reason` | Why the pass got its phase label |

## Things to know

- Days are UTC days: (00:00 to 24:00 UTC), not local days.
- The rain is a satellite estimate: The Late Run is available about a day after the rain, but it is not corrected with rain gauges. NASA's gauge-corrected Final Run comes out about 3.5 months later. In October 2026 it only went up to September 2025, so none of these events have it yet.
- River floods are fed by rain upstream: For Mozambique, Pakistan, Patna and Bhagalpur, much of the water came from rain upstream, outside the box. The box rain shows only the local part.
- Nepal (Trishuli): was caused by a glacier/rock collapse, not by rain.
- Empty cells (no value): NASA leaves out open water, rivers and lakes, towns, snow and frozen ground, and areas with excessive rain. Flooded land is therefore often empty during a flood. Soil moisture is most useful before the flood.
- Coverage differs between tracks: Each track sees a different part of the box, so its average covers different ground. Compare passes of the same track (one line in the chart). The chart labels show how much of the box each pass covers.
- Dense vegetation: Values under dense forest or tall crops are marked "not recommended" by NASA. They're kept in soil_moisture, but mean_sm_recommended_only in the CSV leaves them out.
- Provisional: NASA says this product is only partly checked so far ("partially validated"), and its accuracy goal is ±0.06 m³/m³ where vegetation is not dense.
- Days are UTC in the file names: Local times and labels are in the CSV.
- `01_mozambique_limpopo`: River flood: this flood was driven by the river, so much of the water came from rain upstream, outside this box. Rain over the box shows only the local part.
- `03_pakistan_punjab`: River flood: this flood was driven by the river, so much of the water came from rain upstream, outside this box. Rain over the box shows only the local part.
- `05_nepal_trishuli`: Not a rain flood: the reports give a glacier/rock collapse as the cause, not rain.
- `06_india_bihar_patna`: River flood: this flood was driven by the river, so much of the water came from rain upstream, outside this box. Rain over the box shows only the local part.
- `07_india_bihar_bhagalpur`: River flood: this flood was driven by the river, so much of the water came from rain upstream, outside this box. Rain over the box shows only the local part.

- The notebook does not say where these labels come from or which day they show. It pairs each with the event's NISAR flood-time ("during") scene, and one of its plots titles value 1 "candidate new water", so they are meant as the water at flood time, possibly flood water only rather than every river and lake.
- Covers a larger area than the event box; stats.eventBox gives the numbers inside the box.
- The image is downsampled with an "any water" rule, so thin water looks a little wider than it is; the stats are counted at the native ~30 m.
- Unknown pixels are transparent, like non-water ones; stats.unknownPct says how many there are.
